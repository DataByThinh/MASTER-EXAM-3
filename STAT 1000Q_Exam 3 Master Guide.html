Chapter 5 — Sampling Distribution

Core Symbols

μ = population mean
x̄ = sample mean
μₓ̄ = mean of sampling distribution
σₓ̄ = standard error
σ = population standard deviation

CLT

n ≥ 30
  • Always draw the bell curve
  • Check if population is normal or n ≥ 30
  • np ≥ 15
  • n(1 − p) ≥ 15

Chapter 6 — Confidence Intervals

Confidence Levels

  • 90% → α = 0.10
  • 95% → α = 0.05
  • 98% → α = 0.02
  • 99% → α = 0.01

z* Values

  • 90% → 1.645 (≈ 1.65)
  • 95% → 1.960 (≈ 1.96)
  • 98% → 2.326 (≈ 2.33)
  • 99% → 2.576 (≈ 2.58)
  • invNorm → z*
  • invT → t*
  • Proportion uses z*
  • Answer format: (lower, upper)
  • Using t* instead of z* for proportions
  • Forgetting to convert the confidence level to α
  • Forgetting to convert percentages to decimals
  • Rounding too early → affects the final bounds
  • Identifying the wrong area or the wrong tail for the critical value

Summary of Core Problem Types

  • Z-confidence interval
  • Proportion confidence interval
  • Find critical value
  • Interpret confidence level
  • Required sample size
